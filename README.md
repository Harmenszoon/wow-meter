# Harmenszoon's Meter

Gives Blizzard's built-in damage meter a compact layout in WoW Forever. Class-colored rows show names and values, and the backdrop and title controls appear on hover. Blizzard supplies the combat data and session history.

Enable **Damage Meter** in the game options. **Right-click** the meter to open its settings. **Left-click** a player's row to see the spell breakdown, or **Shift-click** to pin it open. Use Edit Mode to adjust the meter's size and text.

## Installation

In WowUp, select **Get Addons**, then **Install from URL**, and paste this repository's address. [Repository URL](https://github.com/Harmenszoon/wow-meter)

For manual installation, extract the `-forever.zip` release asset into `_forever_/Interface/AddOns/` so it contains `Meter/Meter.toc`. [Download the latest release](https://github.com/Harmenszoon/wow-meter/releases/latest)
